Lição 0003 · Active Record na Margem

Dois tipos de método

No Book convivem métodos que você escreveu e métodos que o Active Record entrega. O passo de hoje é separar os dois pelo que devolvem.

O guia de Active Record Basics, seção CRUD, diz que o Active Record cria os métodos de criar, ler, atualizar e apagar. Book herda isso porque ApplicationRecord herda de ActiveRecord::Base. Você não declara find, new, save, update nem destroy em book.rb.

O que você declara ali, para consulta, são os scopes alphabetical e search. Scope é um class method com nome de consulta. O corpo devolve uma relação, então dá para continuar a cadeia.

Chamada no controllerQuem defineDevolve
Book.alphabetical.search(...) você, no model relação, ainda dá para .page
Book.find(params[:id]) Active Record um Book, ou erro se o id não existe
Book.new e book.save Active Record um Book, depois true ou false
book.update e book.destroy! Active Record atuam naquele registro, não numa relação

Create, Update e Delete ficam para os próximos passos. Hoje a prática é só esta diferença: relação encadeia, registro não.

Book.alphabetical.where(category: "Poesia")   # relação
Book.find(1).where(category: "Poesia")        # erro: Book não tem where

Faça no console

Na raiz do repositório, com a API no ar:

docker compose exec api bundle exec rails console
  1. Book.singleton_methods(false).sort — a lista do que este model definiu na classe. Procure :alphabetical e :search. :find não entra aí.
  2. Book.alphabetical.class — ActiveRecord::Relation.
  3. Book.alphabetical.where(category: "Poesia").class — ainda ActiveRecord::Relation.
  4. Book.find(Book.pick(:id)).class — Book. Se pick vier nil, o catálogo está vazio e esta linha fica para depois.

Recupere sem olhar acima

Os passos

  1. Este: relação contra registro.
  2. Create: new e save, como o BooksController#create.
  3. Update: update no registro que o find carregou.
  4. Delete: destroy!.

A fonte desta lição é a seção CRUD: Reading and Writing Data. O mapa de uma linha por método está na ficha.

Quando terminar o console, manda o que singleton_methods listou. Se um nome te surpreender, pergunta antes de seguir para o Create.
