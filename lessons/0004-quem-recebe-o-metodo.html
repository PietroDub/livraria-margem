Lição 0004 · Active Record na Margem

Quem recebe o método

O ponto chama o método no objeto à esquerda. where existe na relação. find já trocou a relação por um Book.

where e find os dois vêm do Active Record, como o CRUD. O guia separa pelo retorno, na abertura de Retrieving Records: where devolve uma ActiveRecord::Relation; find devolve uma instância do model.

alphabetical é só o nome que você deu a order(:title, :id). Esse order também devolve relação. Por isso a linha de baixo ainda tem para quem mandar o where.

Book.alphabetical.where(category: "Poesia")

Book          .alphabetical          .where(category: "Poesia")
recebe         devolve Relation        quem recebe where
alphabetical                           é essa Relation

category: "Poesia" é um argumento nomeado, o mesmo que passar o hash { category: "Poesia" }. A chave é a coluna, o valor é o filtro. O where guarda isso na relação. A SQL sai assim, no mesmo formato do guia:

SELECT "books".* FROM "books"
WHERE "books"."category" = 'Poesia'
ORDER BY "books"."title" ASC, "books"."id" ASC

A relação ainda não é um livro. Ela é a descrição da consulta. O trecho sobre method chaining diz para encadear enquanto o método anterior devolver relação, e deixar por último o método que devolve um registro.

Book.find(1).where(category: "Poesia")

Book          .find(1)               .where(category: "Poesia")
recebe         devolve um Book         quem recebe where
find                                   é esse Book

A instância tem title, save, update, destroy. Não tem where, porque a consulta já rodou e virou um objeto. O erro é NoMethodError: where não existe em Book.

Book.where(category: "Poesia") funciona sem scope nenhum. A classe encaminha where para Book.all, e all é uma relação. O scope entra quando você quer repetir uma consulta com nome, como alphabetical antes do where.

Faça no console

docker compose exec api bundle exec rails console
  1. rel = Book.alphabetical e depois rel.class. Relação.
  2. rel.respond_to?(:where). true.
  3. book = Book.new e depois book.respond_to?(:where). false.
  4. Book.respond_to?(:where). true: a classe também recebe where, e encaminha para a relação.

Recupere sem olhar acima

Se o respond_to? não bater com esses três, manda o que apareceu. O próximo passo continua sendo o Create, depois que esta cadeia estiver estável.
