Encontrando valores

Compressão da seção 3.4 do guia, com Book e User. A lição que treina a escolha é Valores sem o model.

Fonte: Active Record Query Interface, §3.4. Contratos de pluck, pick e ids: ActiveRecord::Calculations.

O que devolver

MétodoRetornoSQL na horaEncadeia depois
pluck(:isbn) Array de valores sim não
pluck(:id, :title) Array de arrays sim não
pick(:id) valor ou nil sim não
pick(:id, :title) array de uma linha, ou nil sim não
ids Array da chave primária sim não
select(:isbn) relação de models ao carregar sim

Forma curta

Book.where(category: "Poesia").pluck(:isbn)
User.where(email: email).pick(:id)     # limit(1).pluck(:id).first
Book.alphabetical.ids                  # pluck da primary key
Book.limit(2).pluck(:title)            # limite antes
Book.pluck(:title).limit(2)            # NoMethodError

O que não vem junto

  • Nenhum objeto Book ou User. Método de instância e atributo sobrescrito não participam.
  • includes já presente na relação é executado junto com o pluck. Para evitar: unscope(:includes).pluck(...).
  • ids segue primary_key. Aqui é id. Não é isbn nem user_id.

Saída em SQL cru

Mesma seção do guia. Use quando a interface não expressa a consulta. Não é o padrão dos controllers da Margem.

MétodoDevolve
Book.find_by_sql("SELECT ...") Array de Book, mesmo para uma linha
