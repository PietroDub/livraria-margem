Quem recebe o próximo método

O ponto chama o método no objeto que está à esquerda. A regra está em Understanding Method Chaining: a cadeia continua quando o método anterior devolveu uma ActiveRecord::Relation. Quem devolve um registro fica no fim.

Book.alphabetical.where(category: "Poesia")
# alphabetical devolve Relation; where é método dela

Book.find(1).where(category: "Poesia")
# find devolve Book; a instância não tem where

where, order e find são herdados. alphabetical só dá nome ao order(:title, :id). category: "Poesia" é um argumento nomeado: coluna e valor, que o where vira WHERE books.category = 'Poesia'.

new não grava. create grava e devolve o objeto mesmo quando a validação falha. save e update devolvem false nessa falha. O par com ! levanta RecordInvalid. Isso é a seção Validations do mesmo guia; a lição de Create retoma.
